# Umbra

Atlas interactif des éclipses solaires, calculé entièrement dans le navigateur.

- Trajets d'ombre sur planisphère ou globe, de l'an -1999 à 3000
- Positions du Soleil et de la Lune par les séries de Meeus, éléments de Bessel dérivés de la géométrie, ΔT selon Espenak & Meeus
- Circonstances locales en tout point (type, grandeur, obscurcissement, durée)
- Animation de l'ombre, frise chronologique, export GeoJSON des tracés

Site : https://germaincasse.github.io/Umbra/

Page unique sans dépendance ni build : ouvrir `index.html` suffit.
